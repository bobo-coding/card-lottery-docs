## 市场研究结论速查

**形态分界**：随机性来源决定信任架构。Kuji/Oripa 由平台产生随机 → 须密码学自证；
Breaking 随机来自厂商密封盒 → 平台无法操纵内容，靠影像自证。见 §2.1。

**需求风向**：2025 年 TCG 评级量 1680 万张（+95%）首次反超体育卡 1000 万张（−12%）。
而 Breaking 的球队分位机制只在体育卡上成立 —— 增长在 TCG，主导形态却服务体育卡。见 §3.6。

**平台财务对标（披露口径）**：发行层（Topps EBITDA >20%、バンダイ トイホビー段 18.8%、卡游经调整净利率约 44%）
≫ 平台抽成层（take rate 8–14%；eBay 净利率 18%，Whatnot GMV $80 亿仍未盈利）≫ 二级零售层（テイツー营业利润率 3.3%）。
Oripa 是梯度上的异常点（日本トレカセンター净利 ¥23.6 亿、两年 10.6 倍），来源是不透明定价权。
开箱类的钱来自**高频小额**（卡游约 ¥1.7/包、Whatnot AOV $18–28 估）。见 §3.8。

**合规是融资前提**：卡游年营收 ¥100 亿、毛利 67%、市占 71%，未被认定违法，却因"未成年人消费管控 / 盲盒合规"
两次递表失效、对赌触发 ¥13.5 亿回购。**合法 ≠ 可资本化**。见第 4 章。

## 第 2 章　产品形态分类体系

> 范围：**实体卡**的开箱类产品。数字皮肤开箱、盲盒电商、链上卡牌不在范围内。

---

### 2.1 分类框架：八个正交维度

产品形态不应按"叫什么名字"分类，而应按**系统属性**分类。以下八个维度互相正交，
任何一个具体产品都是这八维空间中的一个点。名字（Kuji/Oripa/Breaking）只是常见取值的组合。

| # | 维度 | 取值 | 为什么重要 |
|---|---|---|---|
| **D1** | **随机性来源** | 平台生成 / 厂商密封 | **决定信任架构**，见 §2.3 |
| **D2** | **奖池有限性** | 有限可穷尽 / 无限同分布 | 决定库存模型与是否有尾部博弈 |
| **D3** | **结果确定时点** | 事前封装 / 抽取瞬间 / 物理开封 | 决定库存是实物账还是逻辑账 |
| **D4** | **归属分配方式** | 直接归属 / 分位归属 | 分位引入抢占竞争与成团问题 |
| **D5** | **实时性要求** | 异步 / 直播强实时 | 决定是否需要音视频与长事务 |
| **D6** | **价值回流** | 单向发货 / 回收闭环 / 存管 | 决定资金与库存是单向还是回路 |
| **D7** | **履约时点** | 即时 / 合单延迟 / 长期存管 / 不发货 | 决定仓储与物流复杂度 |
| **D8** | **供给结构** | 自营 / 撮合 / 创作者分销 | 决定概率公信力与责任边界归属 |

### 2.2 形态全谱

#### 2.2.A Kuji 系（有限抽签）

固定口数、无放回、必然穷尽。核心是**等级赏结构 + 尾部奖励**。

| 编号 | 形态 | 说明 |
|---|---|---|
| A1 | 店头实物くじ | 线下纸质抽签，一番くじ原型 |
| A2 | オンラインくじ | 线上化，一番くじONLINE / くじ引き堂 / セガラッキーくじ |
| A3 | スクラッチ型 | 数字刮刮卡开示，本质同上 |
| A4 | ラストワン賞 | 抽走最后一口者额外获奖 |
| A5 | W チャンス | 未中奖票据参与二次抽奖 |
| A6 | 確定枠 | 高价位保证特定等级 |
| A7 | 箱買い / まとめ引き | 一次买断剩余全部或多口 |

**尾部博弈**：随池子消耗，剩余期望值持续变化。高赏未出且余口少时后段明显正期望，
叠加 Last One 赏 → **尾部常被整体买断**。剩余数展示延迟即套利窗口，是并发压测重点。

#### 2.2.B Oripa 系（自制卡包）

平台自行组盘售卖。与 Kuji 同源，但在 D2/D3/D6 上分化出多个分支。

| 编号 | 形态 | 说明 |
|---|---|---|
| B1 | 店头オリパ | 线下卡店自制包，Oripa 的线下原型 |
| B2 | **確率型（无限）** | 每次独立加权采样，库存补充，EV 恒定 |
| B3 | **口数型（有限）** | 定量 N 包，内容清单公开，与 Kuji 同构 |
| B4 | **リアルタイム排出** | 服务端 RNG 在抽取瞬间决定 |
| B5 | **事前封入** | 卡已物理封入编号包，买的是具体某包 |
| B6 | 价格分层 | 低价引流 / 中价主力 / 高额单抽 |
| B7 | **ポイント買取型** | 抽中即可卖回换积分 —— Oripa 的经济核心 |
| B8 | 鑑定品特化 | 专出 PSA10 等评级卡（如 Clove） |
| B9 | ランク型 | 池内分 SS/S/A 档，按档给出保证 |
| B10 | 天井 / 保証枠 / 引き直し | 保底、必含、重抽 |
| B11 | コンプリート型 | 面向集齐套牌，去重逻辑 |
| B12 | 福袋型 | 弱随机的价值捆绑 |

**B2/B3 与 B4/B5 是两组正交分叉**，四种组合都有真实产品，架构上必须先定：

|  | 確率型（无限） | 口数型（有限） |
|---|---|---|
| **リアルタイム排出** | 最灵活，纯逻辑库存 | 有尾部博弈 + 强一致池 |
| **事前封入** | 少见（补包即可） | 天然可审计，但改配置要拆重装 |

#### 2.2.C Breaking 系（直播拆卡）

主播实时拆原厂密封盒，用户事先买"位"，按规则归属。

| 编号 | 形态 | 分位依据 |
|---|---|---|
| C1 | Personal Break | 无分位，整盒归一人，纯代拆服务 |
| C2 | PYT（Pick Your Team） | 球队，各队按热度分别定价，用户挑 |
| C3 | RT（Random Team） | 球队，同价，开拆前当场随机分配 |
| C4 | Tiered RT | 球队分档，同档同价随机 |
| C5 | Pick Your Slot / Pack | 包号或盒内位置（非体育卡常用） |
| C6 | Hit Draft | 先拆完，按抽签顺序轮流挑走稀有卡 |
| C7 | Mixer / Case Break | 多盒合拆，位跨整箱 |
| C8 | Line / Serial Break | 卡面编号规则（如尾数）归属 |
| C9 | Bounty / Cherry Pick | 指定卡设赏金 |
| C10 | Repack Break | 拆平台自行重封的包（**争议最大，见 §2.4**） |

**两段随机，性质完全不同**：

1. **分位随机**（C3/C4/C6）——**平台产生**，须可验证公平，行业惯例要求**随机器当场上镜**
2. **开包随机**——**厂商产生**，平台不可知不可控，只需证明未调包、未预先探测

第一段应用密码学承诺，第二段只能靠影像。**把两者当同一件事设计必然出问题。**

**成团机制**：位未售罄不能开拆 → fill or refund。涉及占位锁定与超时释放、
凑不满的自动退款解冻、临开拆退位禁止（防博弈）。

#### 2.2.D 混合与衍生

| 编号 | 形态 | 说明 |
|---|---|---|
| D1 | Kuji 式 Oripa | 有限池 + Last One，稀缺感更强 |
| D2 | Oripa 式分位 | Breaking 的位以盲盒方式售卖 |
| D3 | Vault / 金库存管 | 抽中默认不发货，存平台，可流通可提货 |
| D4 | 二级流通 | 平台内转让，配合 D3 才成立 |
| D5 | 评级联动 | 抽中直送评级，评完再入库或发货 |

### 2.3 形态 × 维度映射矩阵

| 形态 | D1 随机源 | D2 池 | D3 时点 | D4 归属 | D5 实时 | D6 回流 | D7 履约 |
|---|---|---|---|---|---|---|---|
| **Kuji (A)** | 平台 | 有限 | 抽取 | 直接 | 否 | 少见 | 即时/合单 |
| **Oripa 確率型 (B2)** | 平台 | 无限 | 抽取 | 直接 | 否 | **核心** | 合单/存管 |
| **Oripa 口数型 (B3)** | 平台 | 有限 | 抽取 | 直接 | 否 | **核心** | 合单/存管 |
| **Oripa 事前封入 (B5)** | 平台 | 有限 | **封装时** | 直接 | 否 | 核心 | 合单 |
| **Personal (C1)** | 厂商 | 有限 | 开封 | 直接 | **是** | 少见 | 合单 |
| **PYT (C2)** | 厂商 | 有限 | 开封 | **分位** | **是** | 少见 | 合单 |
| **RT (C3)** | **厂商+平台** | 有限 | 开封 | **分位** | **是** | 少见 | 合单 |
| **Hit Draft (C6)** | 厂商+平台 | 有限 | 开封 | **分位** | **是** | 少见 | 合单 |
| **Vault (D3)** | — | — | — | — | 否 | **存管** | **不发货** |

**读法**：D1 决定信任模块，D2 决定库存模块，D4 决定并发争抢模块，D5 决定是否引入音视频栈，
D6 决定是否需要精算与积分账户。一个平台若要同时做 Oripa 和 Breaking，
则六个模块全部都要建 —— 这是范围决策，不是功能取舍。

### 2.4 三类形态的固有风险（来自真实事故）

架构必须针对这些设计，而非事后补救。详细案例见 §3.5。

| 风险 | 出现在 | 机制 | 架构对策 |
|---|---|---|---|
| **概率不符/虚假封入** | Oripa / Kuji | 宣传的高价卡实际不在池中 | 库存与奖池强绑定；池内容可公示可审计 |
| **抽取结果可操纵** | Oripa / Kuji | 服务端 RNG 不可验证 | 可验证随机（种子承诺 + 事后验算） |
| **分位随机被操纵** | Breaking RT | 随机器结果预设 | 承诺-揭示 + 当场上镜 + 影像归档 |
| **调包 / 预先探测** | Breaking | 拆前已知内容，或换包 | 全程连续影像、封条上镜、来源可溯 |
| **重封包冒充原封** | Breaking C10 | 重封包按原封卖 | Repack 强制标识与隔离，不与原封混售 |
| **托价 / 刷单** | Breaking | 马甲号抬价占位 | 账号关联识别、成交审计 |
| **内部人优待** | Breaking | 好盒定向给关系主播 | 货源分配随机化并留痕 |
| **积分沉淀滥用** | Oripa | 积分只进不出，实为预收 | 积分与资金隔离核算；明确不可提现 |

### 2.6 跨形态公共底座

不论选哪一种，以下能力共用，可先于形态设计动工。
**右列标注本项目（Breaking 形态）的取舍**：

| # | 能力 | 本项目 |
|---|---|---|
| 1 | **可验证随机（Provably Fair）**：种子承诺 + 熵源 + 事后可验算 | ✅ 核心，见 §6.6.1 |
| 2 | **散卡 SKU 与库存**：唯一标识、品相、评级状态、来源溯源 | ✅ 归属与履约依赖 |
| 3 | **卡价与估值**：回收报价与奖池 EV 的共同依赖 | ⚠️ **降级**：无回收则不需估值权，但定价与分位平衡仍需行情源 |
| 4 | **寄存与合单履约** | ⏸ MVP 商家直发；对象模型须预留（§6.8.1） |
| 5 | **开示记录与回放**：抽取日志 + 影像，纠纷仲裁证据链 | ✅ **核心资产**，见 §6.6.2 |
| 6 | **积分/余额账户**：与资金隔离的站内价值载体 | ❌ **排除**：I3 禁可提现余额；仅保留托管与退款 |

## 第 3 章　市场格局

> **本章定位：方向性证据，非论证基础。**

> 而非支撑结构性结论。第 1 章的推导不依赖本章任何数字，
> 数据即使有偏，结构性结论依然成立 —— 三类结论的数据依赖度见 §1.10。
>
> **数据说明**：检索于 2026-09，来源为公开报道与行业媒体。
> 标注 ⚠️ 的条目存在口径冲突或来源不够权威，**引用前须复核**。

### 3.1 一句话格局

**三个区域跑出了三种不同的主导形态，且几乎不重叠：**

| 区域 | 主导形态 | 驱动力 | 成熟度 |
|---|---|---|---|
| **北美/欧洲** | **Breaking**（直播拆卡） | 体育球队情感 + 投资属性 | 高，已平台化寡头化 |
| **日本** | **Oripa + Kuji** | 扭蛋文化原生 + 二级流通发达 | 高，但监管真空 |
| **中国** | 拆卡直播 + 发行方主导 | 学生/年轻群体 + IP 授权 | 中，发行端极度集中 |
| **韩国** | Oripa（跟随日本） | 宝可梦热潮 | 低，野蛮生长 |

**关键判断**：Breaking 和 Oripa 不是竞争关系，而是**不同区域、不同用户心理的两套产品**。
Breaking 卖的是"和主播一起开的社交体验 + 球队归属"，Oripa 卖的是"高频、私密、可回收的博弈循环"。
把两者混做的平台目前很少，这既是空白也是警告。

### 3.2 北美：Breaking 的平台化战争

#### 3.2.1 平台格局

| 平台 | 定位 | 抽成 | 状态 |
|---|---|---|---|
| **Whatnot** | 综合直播电商，卡牌为最大品类 | 约 8% + 支付 | **绝对领先** |
| **Fanatics Live** | 垂直拆卡，深度绑定 Topps/Panini | 6% 统一 | 第二，增速快 |
| **TikTok Shop** | 通用直播电商 | 6% 统一 | ⚠️ **已封禁直播拆卡** |
| **eBay Live** | 老牌二级市场延伸 | 较高（可达 13%+） | 存在感弱 |

#### 3.2.2 Whatnot 关键数据

| 指标 | 数值 |
|---|---|
| 2025 全年 GMV | **> 80 亿美元**（较上年翻倍以上） |
| 2026 上半年 GMV | **已超过 2025 全年**（即 >80 亿美元） |
| 2025 新增账户 | 2000 万+ |
| 累计订单 | 10 亿单 |
| 估值轨迹 | 49.7 亿（2025-01, E 轮 $265M）→ 115 亿（2025 年中, $225M）→ **200 亿**（2026-08, G 轮 $545M） |
| 品类地位 | 体育卡 + TCG 全球前二，美国第一 |
| 品类集中度 | 体育/TCG卡、女装、玩具、美妆 = 美国销售额 74% |
| 平台收入 | 2024 **$3.59 亿** → 2025 **约 $10 亿**（⚠️ Sacra 估算，非披露） |
| **综合变现率** | **约 12.5%** = 佣金 8%（英/欧 6.67%）+ 支付 2.9%+$0.30 + 广告（费率为官网披露定价） |
| 客单价 AOV | ⚠️ **$18–28**（第三方估算区间） |
| **盈利性** | ⚠️ **截至 2025 年中仍未盈利**（Sacra）——GMV $80 亿仍亏损 |

> G 轮由 ICONIQ、Lightspeed、Avra 领投。北美、英国、欧洲最大直播电商平台。

#### 3.3.4 Oripa 的收益结构（重要）

这是 Oripa 与 Kuji/Breaking 的根本差异，直接决定架构：

```
還元率 = 封入卡買取价 ÷ 购买金额
総還元率 = （池内全卡市场价合计 ÷ 池销售总额）
```

**平台的四重利润来源：**

1. **进销价差** —— 按销售相场组池，成本是买取相场，天然有差
2. **ポイント変換カード** —— 未中卡以高于买取价的积分回收，**抬高名义还原率的同时把钱锁在站内**
3. **估值权** —— 卡的价值由平台自行设定
4. **积分沉淀** —— 大多数用户选择换积分继续抽，卡从未离开仓库

> **这四点是 Oripa 的商业模式本体，不是运营技巧。**
> 系统必须原生支持"平台自定估值 + 积分回收 + 库存不出库"，否则做不出这门生意。
> 反过来，**积分只进不出 = 预收款**，是财务与合规上的实质负债，需与资金严格隔离核算。

### 3.7 用户群体分层

#### 3.7.1 五类用户

| 群体 | 核心诉求 | 对形态的偏好 | 商业价值 |
|---|---|---|---|
| **博弈型** | 抽的快感、翻本 | **Oripa 回收闭环**（高频循环） | **ARPU 最高，收入主体** |
| **收藏型** | 集齐、特定卡、品相 | Oripa 定向池 / 二级市场 | 客单中等，留存最好 |
| **投资型** | EV、评级、价格 | 高额 Oripa / Personal Break / 评级联动 | 客单最高，极度价格敏感 |
| **实需型**（打牌） | 便宜拿到特定单卡 | 二级市场，**基本不玩开箱** | 低，但是生态基础 |
| **娱乐型** | 看直播、社交、氛围 | **Breaking**（陪伴感） | 客单低，但撑起流量与直播生态 |

#### 3.7.2 群体 × 形态匹配

```
                  博弈型   收藏型   投资型   实需型   娱乐型
Oripa 回收闭环      ★★★     ★★      ★★      —       ★
Oripa 高额/鑑定品   ★★      ★★      ★★★     —       —
Kuji 有限池         ★★      ★★★     ★★      —       ★
Breaking RT/PYT     ★★      ★       ★★      —       ★★★
Breaking Personal   —       ★★      ★★★     ★       ★
金库存管 + 二级      —       ★★★     ★★★     ★★★     —
```

**读法**：
- **Oripa 的钱来自博弈型**，回收闭环就是为这个群体设计的循环装置
- **Breaking 的流量来自娱乐型**，但利润来自投资型买 Personal Break
- **实需型不玩开箱**，但没有他们二级市场就没有流动性，卡价就没有锚 —— 而卡价是回收报价与 EV 的基础
- **投资型是最危险的用户**：他们会算 EV、会算还原率、会公开质疑概率。**信任架构本质是为他们建的**

#### 3.7.3 区域 × 群体差异

| 区域 | 主力群体 | 特征 |
|---|---|---|
| 日本 | 博弈型 + 收藏型 | 扭蛋文化原生，**还原率认知度高**，会主动比较各站还原率 |
| 北美 | 娱乐型 + 投资型 | 球队情感驱动，评级/投资属性重，社区舆论监督强 |
| 中国 | 娱乐型 + 收藏型 | 学生与年轻群体为主，**未成年人保护是硬约束** |
| 韩国 | 博弈型 | 快速跟随日本，**含未成年人参与，监管风险最高** |

> 日本用户会算还原率，这是产品设计的直接约束：**还原率必须能自圆其说且经得起公开比较**。
> 这也解释了为什么日本平台普遍主动公示"総還元率 95%+"—— 那是竞争必需品，不是善意。

3. **客单价两极**：中国发行层是"¥1.7/包 × 48 亿包"的极低客单×极高频结构；

1. **形态选择上，Oripa 的商业模型最强**：日本头部两年净利 10.6 倍、自有资本比率升至 63%，

   **天然指向池抽形态** —— 这是形态与需求的结构性匹配。

3. **Breaking 的护城河在直播生态与主播关系，不在技术**；且依附第三方平台有被单方面切断的风险
   （TikTok 已封禁）。若无直播运营能力，不建议以此为主形态。

4. **信任架构不是合规成本，是产品竞争力**。日本用户比还原率、北美社区曝光造假、
   韩国因零监管被称变种赌博 —— **可验证随机 + 池内容可审计应作为不可绕过的强制路径**，
   而非事后补的功能。这也是监管收紧时唯一的安全垫。

5. **积分沉淀是实质负债**，必须与资金隔离核算。这一条越早进架构越好，事后拆账极痛苦。

### 4.3 新增约束维度：资本市场可接受性

**卡游案例给 §1.3 的推导链补了一层：**

```
原有链条：
  法律风险源 → 法律硬约束 L1–L4 → 系统不变量 I1–I9

补充链条：
  资本市场/监管叙事风险 → 「可被定性为什么」 → 融资与退出通道
```

| 层级 | 判据 | 后果 |
|---|---|---|
| **法律层** | 是否违法 | 违法 → 处罚、停业 |
| **资本层** | **是否可被定性为"收割未成年人""变相赌博"** | 被定性 → **上不了市、融不到钱** |

> **关键区别：合法 ≠ 可资本化。**
> 卡游没有被认定违法，但监管与舆论把它的模式定性为"灰色地带"，
> 交易所与备案环节就此卡住。**这个门槛比法律门槛更高。**

#### 4.3.1 对本项目的直接含义

| 项 | 含义 |
|---|---|
| L1–L4 的价值被重估 | 不只是避免行政/刑事风险，更是**保留融资与退出通道** |
| 日本 Oripa 同样承压 | 媒体已批"搾取"结构（§3.3.5），DOPA 等若要资本化会遇到同型问题 |
| **本平台的资本叙事** | "可验证公正性"是**唯一能把自己从赌博叙事里摘出来的故事** |
| 未成年人策略 | 中国实证显示未成年人限制直接冲击营收 —— **早期就要明确年龄门槛与验证**<br>⚠️ **2026-09-24 用户决定不做年龄验证与未成年人专项功能**，本条推论作为已接受风险记录于 §8.15 R13 |

> **推论**：§1.2 的信任架构（三方分权、可验证随机、开盒记录）
> 此前的定位是"产品竞争力"。卡游案例说明它还有第二重作用 ——
> **它是这门生意能否被资本市场接受的前提条件。**

### 4.4 毛利率梯度：价值链位置

| 层 | 公司 | 毛利率 | 趋势 |
|---|---|---|---|
| **自有 IP + 发行** | 泡泡玛特 | **69.7%**（2026H1） | 高位 |
| **发行（授权 IP）** | 卡游 | **67.3%**（卡牌 71.3%） | 高位 |
| 制造+发行（授权 IP） | 布鲁可 | **44.3%**（2026H1） | **下滑**（上年 48.4%） |
| 小规模授权玩具 | 52TOYS | **约 40%** | 且**持续亏损** |

> **钱在 IP / 发行层，不在分销层。**
> 开箱平台属于**分销与服务层**，结构上拿不到 60–70% 的毛利。
> 这与第 7 章的判断一致 —— 平台是**佣金生意**，
> 而佣金率受商家毛利约束，商家毛利又受盒价公开的溢价上限约束（透明性悖论）。

**另一条趋势值得注意**：布鲁可毛利率一年内从 48.4% 降至 44.3%，52TOYS 约 40% 且亏损扩大。
**没有自有 IP 的玩家正被上下游挤压。**

### 4.5 泡泡玛特：周期性警告

| 指标 | 2026 H1 |
|---|---|
| 营收 | ¥171.73 亿（+23.8%） |
| 毛利率 | 69.7% |
| 经调整净利 | ¥51.56 亿（+9.5%），净利率 30% |
| **vs 市场预期** | **未达** —— 预期营收 ¥199.8 亿、净利 ¥66.4 亿 |
| 中国 | ¥122 亿（**+47.3%**），占 71% |
| **亚太 / 美洲** | **−9.7% / −16.5%**（线上渠道降温） |
| 股价 | 2026-08-21 收 HK$149，市值 HK$1,984 亿，**较 2025-08 高点腰斩过半** |

**FY2025 年报补充（用户结构指标）**：

| 指标 | FY2025 |
|---|---|
| 中国内地累计注册会员 | **7,258 万**（一年净增 2,650 万） |
| 会员贡献销售额占比 | **93.7%** |
| 会员复购率 | **55.7%** |
| 净利润增速 | +293%（热潮峰值；2026H1 已降至 +9.5%） |

> 年报未披露人均消费/客单价；但"会员贡献 93.7% + 复购率 55.7%"说明收入主体是
> **高频复购的存量会员**，与卡游 ¥1.7/包 × 48 亿包（§4.2.1）同构 ——
> 中国发行层的两家头部都是"低客单、高频次、高复购"结构。
> 这与 §3.8 北美平台 AOV $18–28 的观察一致：
> **开箱类的钱来自高频小额**。

> **两条推论**：
> 1. **该品类是强 hype 驱动的**（2025 年净利曾 +293%，2026 H1 增速降至 +9.5%）。
>    **不要用热潮期增长率做规划假设。**
> 2. **海外扩张不是必然成功**：泡泡玛特带着最强 IP 和最高毛利，海外仍出现两位数下滑。
>    这对"从零进入日本市场"是一个清醒剂 —— 见 §5.9 获客风险。

### 4.6 52TOYS：无自有 IP 的结构困境

| 指标 | 2022 | 2023 | 2024 |
|---|---|---|---|
| 营收 | ¥4.63 亿 | ¥4.82 亿 | ¥6.30 亿（CAGR 16.7%） |
| **净亏损** | ¥170.8 万 | ¥7,193.4 万 | **¥1.22 亿**（持续扩大） |
| 毛利率 | — | — | 约 40% |

- 估值约 **¥42.89 亿**，对比 2021 年 C 轮 ¥42.50 亿 —— **五年几乎零增长**
- **核心 IP 授权集中到期**：史迪奇、草莓熊（2026）；猫和老鼠、蜡笔小新（2027）
- 市占仅 **1.2%**，排名第七

#### 4.6.1 本项目的结构性优势

> **Breaking 平台的标的是厂商已发行的密封产品，从二级渠道采购，不需要 IP 授权。**
>
> 52TOYS 与卡游的头号风险 —— **授权临期、续约议价、IP 方分成** —— 在本模式中**不存在**。
> 这是此前章节未识别的一项优势。
>
> **但对称的代价**：没有 IP 授权，也就**没有 IP 护城河** ——
> 谁都能采购同样的密封盒。护城河只能建立在
> §1.2 的信任架构与 §7.8 的运营效率上，
> 这两者恰好都是产品文档的设计重心（第 1、6、7 章）。
