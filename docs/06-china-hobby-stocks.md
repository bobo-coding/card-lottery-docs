# 中国 Hobby 板块：上市公司证据

> 前置：[00 体系总纲](./00-framework.md) · [02 市场格局](./02-market-landscape.md)
>
> **本文定位**：中国市场**不是本项目的目标市场，也不是竞品**（目标是日本）。
> 看它的理由是方法论上的 —— **上市公司财报是本套文档中唯一经审计、可追溯的数据源**。
> 用途是**校准行业结构判断的量级**，以及观察**监管与资本市场对"开箱类业务"的真实态度**。
>
> ⚠️ 本文为产品战略分析，**非投资建议**，不含任何证券买卖意见。

---

## 0. 三条结论

1. **卡游案例证明：开箱类业务的瓶颈不是法律，是"资本市场可接受性"。**
   ¥100 亿营收、67% 毛利、71% 市占的绝对龙头，**依然上不了市** ——
   这给 [00 §3](./00-framework.md) 的约束推导链补上了一个此前缺失的维度。
2. **毛利率梯度揭示价值链位置**：钱在 IP/发行层（67–70%），
   不在分销层。开箱平台是服务层，**结构上拿不到发行层的毛利**。
3. **本项目天然规避了该板块的头号风险**：Breaking 卖的是厂商已发行的密封品，
   **不需要 IP 授权** —— 52TOYS/卡游面临的"授权临期"风险不存在。

## 2. 卡游：经营优秀 ≠ 能上市

**这是全文最有价值的案例。**

### 2.1 经营数据（优秀）

| 指标 | 2024 |
|---|---|
| 营收 | **¥100.57 亿** |
| 经调整净利 | **¥44.66 亿** |
| 综合毛利率 | **67.3%** |
| **卡牌业务毛利率** | **71.3%**（高于泡泡玛特） |
| 卡包销量 | **48 亿包** |
| TCG 玩具市占 | **71.1%** |
| IP 结构 | 69 个授权 + **仅 1 个自有** |

### 2.2 上市历程（失败）

```
2024-01  首次递表港交所
2024-07  失效 ← 港交所要求补充：未成年人消费管控、盲盒合规、数据安全
2025-04  二次递表
2025-06  通过聆讯
2025-10  再次失效（超期未聆讯）
2026-06  对赌大限已过，至今无第三次递表
```

### 2.3 代价

- 2021-06 红杉中国、腾讯 A 轮，**5 年内未上市则按发行价 +8% 年息回购**
- 回购金额约 **¥13.5 亿**，触发几乎成定局
- 金融负债公允价值达 **¥95.36 亿**，2024 年因此产生 **¥38.67 亿账面亏损**

> **一家年赚 ¥44 亿的公司，因上市失败而背上 ¥95 亿金融负债与 ¥38 亿账面亏损。**

### 2.4 卡不住的是什么

| 阻碍 | 事实 |
|---|---|
| 核心用户年龄 | **6–14 岁儿童** |
| 监管问询 | 未成年人消费管控、盲盒合规、数据安全、儿童个人信息保护 |
| 舆论 | 人民日报发文批"盲卡乱象" |
| 投诉 | 黑猫投诉 **11,448 条**，含诱导消费、未成年人无管控购买 |
| 政策实证 | **2023 年 6 月盲盒新规**（禁向 8 岁以下销售）后，卡游 2023 年**营收与净利双降** |

> **最后一行是硬证据**：监管对这类业务的杀伤力**已被实证**，不是推测。
> 一条针对未成年人的销售限制，直接让行业龙头当年营收净利双降。

## 3. 新增约束维度：资本市场可接受性

**卡游案例给 [00 §3](./00-framework.md) 的推导链补了一层：**

```
原有链条：
  法律风险源 → 法律硬约束 L1–L4 → 系统不变量 I1–I9

补充链条：
  资本市场/监管叙事风险 → 「可被定性为什么」 → 融资与退出通道
```

| 层级 | 判据 | 后果 |
|---|---|---|
| **法律层** | 是否违法 | 违法 → 处罚、停业 |
| **资本层** | **是否可被定性为"收割未成年人""变相赌博"** | 被定性 → **上不了市、融不到钱** |

> **关键区别：合法 ≠ 可资本化。**
> 卡游没有被认定违法，但监管与舆论把它的模式定性为"灰色地带"，
> 交易所与备案环节就此卡住。**这个门槛比法律门槛更高。**

### 3.1 对本项目的直接含义

| 项 | 含义 |
|---|---|
| L1–L4 的价值被重估 | 不只是避免行政/刑事风险，更是**保留融资与退出通道** |
| 日本 Oripa 同样承压 | 媒体已批"搾取"结构（[02 §3.5](./02-market-landscape.md)），DOPA 等若要资本化会遇到同型问题 |
| **本平台的资本叙事** | "可验证公正性"是**唯一能把自己从赌博叙事里摘出来的故事** |
| 未成年人策略 | 中国实证显示未成年人限制直接冲击营收 —— **早期就要明确年龄门槛与验证** |

> **推论**：[00 §2](./00-framework.md) 的信任架构（三方分权、可验证随机、开盒记录）
> 此前的定位是"产品竞争力"。卡游案例说明它还有第二重作用 ——
> **它是这门生意能否被资本市场接受的前提条件。**

## 4. 毛利率梯度：价值链位置

| 层 | 公司 | 毛利率 | 趋势 |
|---|---|---|---|
| **自有 IP + 发行** | 泡泡玛特 | **69.7%**（2026H1） | 高位 |
| **发行（授权 IP）** | 卡游 | **67.3%**（卡牌 71.3%） | 高位 |
| 制造+发行（授权 IP） | 布鲁可 | **44.3%**（2026H1） | **下滑**（上年 48.4%） |
| 小规模授权玩具 | 52TOYS | **约 40%** | 且**持续亏损** |

> **钱在 IP / 发行层，不在分销层。**
> 开箱平台属于**分销与服务层**，结构上拿不到 60–70% 的毛利。
> 这与 [05](./05-unit-economics.md) 的判断一致 —— 平台是**佣金生意**，
> 而佣金率受商家毛利约束，商家毛利又受盒价公开的溢价上限约束（透明性悖论）。

**另一条趋势值得注意**：布鲁可毛利率一年内从 48.4% 降至 44.3%，52TOYS 约 40% 且亏损扩大。
**没有自有 IP 的玩家正被上下游挤压。**

## 5. 泡泡玛特：周期性警告

| 指标 | 2026 H1 |
|---|---|
| 营收 | ¥171.73 亿（+23.8%） |
| 毛利率 | 69.7% |
| 经调整净利 | ¥51.56 亿（+9.5%），净利率 30% |
| **vs 市场预期** | **未达** —— 预期营收 ¥199.8 亿、净利 ¥66.4 亿 |
| 中国 | ¥122 亿（**+47.3%**），占 71% |
| **亚太 / 美洲** | **−9.7% / −16.5%**（线上渠道降温） |
| 股价 | 2026-08-21 收 HK$149，市值 HK$1,984 亿，**较 2025-08 高点腰斩过半** |

> **两条推论**：
> 1. **该品类是强 hype 驱动的**（2025 年净利曾 +293%，2026 H1 增速降至 +9.5%）。
>    **不要用热潮期增长率做规划假设。**
> 2. **海外扩张不是必然成功**：泡泡玛特带着最强 IP 和最高毛利，海外仍出现两位数下滑。
>    这对"从零进入日本市场"是一个清醒剂 —— 见 [03 §9](./03-breaking-mechanics-japan.md) 获客风险。

## 6. 52TOYS：无自有 IP 的结构困境

| 指标 | 2022 | 2023 | 2024 |
|---|---|---|---|
| 营收 | ¥4.63 亿 | ¥4.82 亿 | ¥6.30 亿（CAGR 16.7%） |
| **净亏损** | ¥170.8 万 | ¥7,193.4 万 | **¥1.22 亿**（持续扩大） |
| 毛利率 | — | — | 约 40% |

- 估值约 **¥42.89 亿**，对比 2021 年 C 轮 ¥42.50 亿 —— **五年几乎零增长**
- **核心 IP 授权集中到期**：史迪奇、草莓熊（2026）；猫和老鼠、蜡笔小新（2027）
- 市占仅 **1.2%**，排名第七

### 6.1 本项目的结构性优势

> **Breaking 平台的标的是厂商已发行的密封产品，从二级渠道采购，不需要 IP 授权。**
>
> 52TOYS 与卡游的头号风险 —— **授权临期、续约议价、IP 方分成** —— 在本模式中**不存在**。
> 这是此前文档未识别的一项优势。
>
> **但对称的代价**：没有 IP 授权，也就**没有 IP 护城河** ——
> 谁都能采购同样的密封盒。护城河只能建立在
> [00 §2](./00-framework.md) 的信任架构与 [05 §8](./05-unit-economics.md) 的运营效率上，
> 这两者恰好都是本套文档的设计重心。

## 7. 对本项目的推论汇总

| # | 推论 | 依据 |
|---|---|---|
| 1 | **合规是融资前提，不只是法务事项** | 卡游 ¥100 亿营收仍上市失败（§2） |

| 7 | **未成年人限制对营收的杀伤已被实证** | 2023 盲盒新规后卡游营收净利双降（§2.4） |
