## 核心结论速查

**形态分界**：随机性来源决定信任架构。Kuji/Oripa 由平台产生随机 → 须密码学自证；
Breaking 随机来自厂商密封盒 → 平台无法操纵内容，靠影像自证。见 [01 §1](docs/01-product-taxonomy.md)。

**需求风向**：2025 年 TCG 评级量 1680 万张（+95%）首次反超体育卡 1000 万张（−12%）。
而 Breaking 的球队分位机制只在体育卡上成立 —— 增长在 TCG，主导形态却服务体育卡。
见 [02 §6](docs/02-market-landscape.md)。

**核心矛盾**：Breaking 的信任优势（厂商封盒）与毛利劣势（无回收闭环）互相咬死；
修复毛利的手段（加回收）恰好摧毁信任优势并触及赌博风险。见 [03 §0](docs/03-breaking-mechanics-japan.md)。
[05](docs/05-unit-economics.md) 进一步指出二者**其实是同一属性的两面**（透明性悖论），
且 L1+L3 强制 100% 实物履约，使成本曲线从"软件扩张"变为"人力扩张"。

**集中化是 MVP 前提**：经济上（k=1 逐位发货需 +41% 溢价才保本）与信任上
（I5 录像采集无法在商家自有场地强制）两条独立推理，都指向 MVP 即需**平台集中仓 + 集中开盒**。

**合规是融资前提，不只是法务事项**：卡游年营收 ¥100 亿、毛利 67%、市占 71%，
未被认定违法，却因"未成年人消费管控 / 盲盒合规"两次递表失效、对赌触发 ¥13.5 亿回购。
**合法 ≠ 可资本化** —— 信任架构因此是资本叙事的前提，不只是产品竞争力。
见 [06](docs/06-china-hobby-stocks.md)、[00 §3.0](docs/00-framework.md)。

**平台财务对标（披露口径）**：跨区域利润率梯度一致 ——
**发行层**（Topps EBITDA >20%、バンダイ トイホビー段 18.8%、卡游经调整净利率约 44%）
≫ **平台抽成层**（take rate 8–14%；成熟态 eBay 净利率 18%，直播态 Whatnot GMV $80 亿仍未盈利）
≫ **二级零售层**（テイツー营业利润率 3.3%）。
Oripa 层是梯度上的异常点（日本トレカセンター净利 ¥23.6 亿、两年 10.6 倍），
异常来源是不透明定价权 —— 恰好是 Breaking 因透明性而放弃的东西（透明性悖论的市场实证）。
客单价普遍两极：开箱类的钱来自**高频小额**（卡游约 ¥1.7/包、Whatnot AOV $18–28 估）。
见 [02 §8](docs/02-market-landscape.md)。

**关键设计**：
- 分位单元用 **キャラクター枠**（角色枠）替代球队 —— 唯一具备球队三属性的日本 TCG 分区
- **直播是增益，录像是底座** —— 日本仅 5.8% 买过直播商品；影像的第一定位是审计凭证

**平台形态（多商家市场）**：引入第三方商家后，商家成为新的作弊面
（北美三起信任危机均为第三方商家在平台上作弊）。解法是**三方分权**——
厂商定内容、平台定分位随机与录像、商家两者皆无权，任何单方都无法独自操纵。
四条法律约束升级为**系统不可绕过的不变量 I1–I9**，商家配置不出违规场次。
见 [04](docs/04-platform-product-design.md)。

**产品预案：功能参考 HOBBY STOCKS，前端参考 DOPA**：HOBBY STOCKS（中国大陆拆卡 App，
与 06 的上市公司板块无关）是同为 Breaking 为主的多商家平台，功能骨架（组队拆卡、卡片仓库、查价、评级、商城）
可整体借用，其"卡片仓库"也旁证了 05 的集中仓 + 合单结论。但两个核心部件必须替换：
分队单元球队 → キャラクター枠；商家主播自播开盒 → 平台集中开盒 + 录像（I5）。
其公开的未成年人消费事件说明**实名 ≠ 年龄管控**，支付限额与冷静期升为 P0。
DOPA 只借界面语言，点数 / ポイント変換 / 消费等级等机制一律不借；**演出只能播放已确定的真实结果**。
MVP 只做服务于实测 `m`/`k` 的功能，**不做直播**。分队细则须实机走查补全。
**功能量重心在后台**：26 个模块中运营端 9 个，MVP 54 页中运营端 19 页 ——
Breaking 平台的产品本质是一套**履约操作系统**，用户 App 只是前台（05 §7 运营密集型的产品侧体现）。
见 [07](docs/07-product-feature-spec.md)。
